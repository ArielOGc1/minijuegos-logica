# Minijuegos de lógica

Minijuegos en español para practicar lógica de programación desde cero, sin instalar nada.

Para jugar: https://arielogc1.github.io/minijuegos-logica/

- `juegos/`: un archivo HTML autocontenido por concepto.
- `registro.json`: conceptos del curso y su estado.
- `AGENTE.md`: instrucciones del agente que crea cada entrega.
- `pruebas/`: juegan cada minijuego en un navegador real.

Para generar la portada y ejecutar las pruebas:

```bash
npm install
npm run portada
npm test
```

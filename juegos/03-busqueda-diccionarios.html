Entrega 3: búsqueda con diccionarios y duplicados

0 de 6 resueltos

Buscar en una lista obliga a recorrerla entera, pero un diccionario o un conjunto encuentra un valor casi al instante. Esa diferencia convierte muchos problemas de dos bucles en uno solo, y es la misma idea que hay detrás de detectar duplicados en una tabla con GROUP BY y HAVING.

Cómo practicar

  1. Descarga el archivo y ábrelo en tu editor.
  2. Completa las funciones y las consultas.
  3. Ejecuta python entrega_03.py para ver qué casos pasan. Solo necesitas Python: SQLite viene incluido.
  4. Si te atascas, pide una pista. Al terminar, compara con la solución.

Python

1. Identificadores repetidos

Escribe tiene_duplicados para que devuelva True si algún id aparece más de una vez y False si no. Los repetidos no tienen por qué estar seguidos.

  • tiene_duplicados([1, 2, 3, 1]) devuelve True
  • tiene_duplicados([1, 2, 3]) devuelve False
  1. Recorre los ids una vez y recuerda los que ya has visto.
  2. Un conjunto es la estructura adecuada para preguntar si ya viste un valor.
  3. Antes de añadir cada id, comprueba si ya está en el conjunto. Si está, ya tienes la respuesta.
Ver solución 
def tiene_duplicados(ids):
    vistos = set()
    for i in ids:
        if i in vistos:
            return True
        vistos.add(i)
    return False

Cada consulta al conjunto es casi inmediata, así que el tiempo crece en proporción a la lista. También valdría len(set(ids)) != len(ids), aunque esa versión no se detiene al encontrar el primer repetido.

SQL

2. Correos repetidos

Obtén los correos que aparecen más de una vez y cuántas veces lo hacen. Las filas sin correo no cuentan. Ordena por veces de mayor a menor y, si hay empate, por correo.

  1. Agrupa por correo y cuenta las filas de cada grupo.
  2. Una condición sobre el conteo de un grupo no puede ir en WHERE.
  3. GROUP BY reúne todos los NULL en un mismo grupo: tienes que descartarlos antes de agrupar.
Ver solución 
SELECT email, COUNT(*) AS veces
FROM usuarios
WHERE email IS NOT NULL
GROUP BY email
HAVING COUNT(*) > 1
ORDER BY veces DESC, email;

La trampa está en los NULL: sin el WHERE, aparecen como un grupo más con dos filas. WHERE actúa sobre filas antes de agrupar y HAVING sobre los grupos ya formados.

Python

3. Dos importes que suman el total

Recibes una lista de importes y un objetivo. Escribe indices_suma para que devuelva [i, j], con i < j, los índices de los dos importes que suman el objetivo. Hay como mucho una pareja válida. Si no existe, devuelve []. Un importe no se puede usar dos veces.

  • indices_suma([2, 7, 11, 15], 9) devuelve [0, 1]
  • indices_suma([3, 2, 4], 6) devuelve [1, 2]
  • indices_suma([1, 2], 10) devuelve []
  1. Con dos bucles funciona, pero intenta resolverlo recorriendo la lista una sola vez.
  2. Para cada importe, ya sabes exactamente qué otro valor necesitas para llegar al objetivo.
  3. Guarda en un diccionario los importes ya vistos junto con su índice, y consúltalo antes de guardar el importe actual.
Ver solución 
def indices_suma(importes, objetivo):
    vistos = {}
    for j, importe in enumerate(importes):
        falta = objetivo - importe
        if falta in vistos:
            return [vistos[falta], j]
        vistos[importe] = j
    return []

Consultar antes de guardar evita usar el mismo importe dos veces y resuelve los valores repetidos, como en [3, 3]. Así se pasa de comparar todas las parejas a un único recorrido.

4. Pedidos registrados dos veces

Un pedido está duplicado si coinciden el cliente, el producto y la fecha. Obtén esas combinaciones y cuántas copias tiene cada una. Ordena por cliente, producto y fecha.

  1. Lo que define un duplicado es la combinación completa, no una sola columna.
  2. GROUP BY admite varias columnas separadas por comas.
  3. Ana compró el mismo teclado dos días distintos: esas compras no deben sumarse en el mismo grupo.
Ver solución 
SELECT cliente, producto, fecha, COUNT(*) AS copias
FROM pedidos
GROUP BY cliente, producto, fecha
HAVING COUNT(*) > 1
ORDER BY cliente, producto, fecha;

Esta es la forma habitual de auditar duplicados en una tabla. Ten cuidado: SQLite permite seleccionar columnas que no están en el GROUP BY y elige un valor cualquiera, mientras que otros motores lo rechazan.

Python

5. El primero en repetirse

Escribe primer_repetido para que devuelva el id cuya segunda aparición llega antes. Si ninguno se repite, devuelve None.

  • primer_repetido([1, 2, 3, 2, 1]) devuelve 2
  • primer_repetido([5, 1, 5, 1]) devuelve 5
  • primer_repetido([1, 2, 3]) devuelve None
  1. Fíjate en el primer ejemplo: el 1 aparece antes, pero el 2 es el primero en volver a aparecer.
  2. Solo puedes detectar una repetición en el momento en que la encuentras al recorrer la lista.
  3. Es muy parecido al primer ejercicio: cambia únicamente lo que devuelves.
Ver solución 
def primer_repetido(ids):
    vistos = set()
    for i in ids:
        if i in vistos:
            return i
        vistos.add(i)
    return None

Contar con ids.count responde otra pregunta: cuál es el primer valor que tiene repetición. El conjunto detecta la repetición justo cuando ocurre, en orden de llegada.

6. Usuarios con el mismo teléfono

Encuentra las parejas de usuarios que comparten teléfono. Cada pareja debe salir una sola vez, con el usuario de id menor primero. Ordena por teléfono, id del primero e id del segundo.

  1. Necesitas comparar cada fila con otras de la misma tabla: une la tabla consigo misma usando dos alias.
  2. Unir por teléfono igual también empareja a cada usuario consigo mismo y genera cada pareja dos veces.
  3. Una sola condición sobre los ids de los dos alias resuelve los dos problemas a la vez.
Ver solución 
SELECT a.nombre AS nombre_1, b.nombre AS nombre_2, a.telefono
FROM usuarios a
JOIN usuarios b
  ON a.telefono = b.telefono
 AND a.id < b.id
ORDER BY a.telefono, a.id, b.id;

Con a.id < b.id nadie se empareja consigo mismo y cada pareja aparece una vez. Los NULL quedan fuera sin hacer nada, porque NULL = NULL no se considera verdadero en SQL.
